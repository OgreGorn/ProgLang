`x & (x-1) = 000...000`

### Задание 4 **(3)**
*Обоснуйте корректность работы программы "Разложение числа по степеням двойки" из лекции.
Требуется определить, что будет результатом выражения `x&-x`.*

Пусть двоичная запись положительного числа `x` заканчивается некоторым количеством нулей:

`x = ...1 00...00`

Для изменения знака в дополнительном коде используется формула из лекции:

`-x = ~x + 1`

После инверсии:

`~x = ...0 11...11`

После прибавления единицы:

`-x = ...1 00...00`

Все биты левее самой младшей единицы у `x` и `-x` при операции `&` уничтожаются, а самая младшая единица остается:

`x & -x = 00...0100...00`

Следовательно, `x&-x` возвращает число, в двоичной записи которого содержится только самая младшая единица исходного `x`.

Это число является степенью двойки.

В программе:

```cpp
int t = x & -x;
x -= t;
```

на каждой итерации находится одна степень двойки, входящая в двоичное разложение `x`, после чего она вычитается. Поэтому программа последовательно находит все единичные биты числа и тем самым раскладывает его по степеням двойки.

* *Можно ли указанным способом сохранить более 8 чисел? Обоснуйте ответ.*

Нет, если сохранять числа из диапазона от 0 до 15 в одной 32-битной переменной тем же способом.

Для каждого такого числа требуется 4 бита:

`0...15 = 0000...1111`

В лекции используется стандартное целое число длиной 32 бита.

Поэтому:

`32 / 4 = 8`

Можно сохранить ровно 8 четырехбитных чисел.

* *Сколько чисел можно будет сохранить при изменении диапазона от 0 до 7? Обоснуйте ответ.*

Для диапазона от 0 до 7 достаточно трех бит:

`0...7 = 000...111`

В 32 битах полностью помещается:

`32 / 3 = 10`

То есть можно сохранить 10 чисел, используя 30 бит. Два бита останутся свободными.

* *В чем смысл <<магической>> константы 15 в тексте программы?*

В программе используется:

```cpp
v & 15
```

Число 15 в двоичном виде:

`15 = 1111₂`

Операция `&` с `1111` оставляет только четыре младших бита числа `v` и обнуляет остальные.

Так как каждое сохраненное число занимает 4 бита, выражение `v & 15` извлекает последнее упакованное число.

* *Если по условию задачи надо будет сохранить только числа в интервале от 0 до 10, то следует ли заменить
эту константу на 10? Обоснуйте ответ.*

Нет.

Числа от 0 до 10 по-прежнему требуют 4 бита, поскольку:

`10 = 1010₂`

Для извлечения всех четырех битов нужна маска:

`1111₂ = 15`

Если заменить 15 на 10:

`10 = 1010₂`

то операция `v & 10` сохранит только те биты, которым соответствуют единицы в маске `1010`, и часть информации будет потеряна.

Поэтому константа должна остаться равной:

`15`
