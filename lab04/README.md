### Задание 1 **(3)**
* *Запишите двоичное представление числа -99 в целочисленном знаковом типе длиной 1, 2, 4 байта.* 



### Решение

#### 1. Двоичное представление числа -99

По лекции целые числа хранятся в памяти в виде двоичных последовательностей определённой длины.

Также используется дополнительный код. Чтобы получить `-x`, используется формула:

`-x = ~x + 1`

То есть сначала нужно получить двоичную запись положительного числа, затем:

1. инвертировать все биты;
2. прибавить `1`.

Сначала запишем число `99` в двоичном виде.

Разложим 99 по степеням двойки:

`99 = 64 + 32 + 2 + 1`

То есть:

`99 = 2^6 + 2^5 + 2^1 + 2^0`

Получаем:

`99 = 1100011`

---

##### Тип длиной 1 байт

1 байт содержит 8 бит, поэтому дописываем слева один ноль:

`99 = 01100011`

Инвертируем все биты:

`01100011 -> 10011100`

Прибавляем 1:

`10011100 + 1 = 10011101`

Следовательно:

`-99 = 10011101`

---

##### Тип длиной 2 байта

2 байта содержат 16 бит.

Записываем положительное число 99 с помощью 16 бит:

`00000000 01100011`

Инвертируем все биты:

`11111111 10011100`

Прибавляем 1:

`11111111 10011100 + 1 = 11111111 10011101`

Следовательно:

`-99 = 11111111 10011101`

---

##### Тип длиной 4 байта

4 байта содержат 32 бита.

Записываем 99 с помощью 32 бит:

`00000000 00000000 00000000 01100011`

Инвертируем все биты:

`11111111 11111111 11111111 10011100`

Прибавляем 1:

`11111111 11111111 11111111 10011100 + 1`

Получаем:

`11111111 11111111 11111111 10011101`

Следовательно:

`-99 = 11111111 11111111 11111111 10011101`

### Задание 2 **(3)**
*Напишите пример программы на С++ с использованием целочисленных литералов в разных форматах записи, 
разной длины, знаковых и беззнаковых. 
Пример должен охватывать большинство способов записи целочисленных литералов.*

### Решение

По лекции целочисленные литералы могут записываться в разных системах счисления.

Используются следующие префиксы:

- без префикса — десятичная запись;
- `0` — восьмеричная запись;
- `0b` или `0B` — двоичная запись;
- `0x` или `0X` — шестнадцатеричная запись.

Также можно использовать суффиксы:

- `U` или `u` — беззнаковый тип;
- `L` или `l` — `long`;
- `LL` или `ll` — `long long`.

Напишем программу, в которой используются эти варианты:

```cpp
#include <iostream>

int main() {
    int a = 100;                    // десятичная запись
    int b = 0144;                   // восьмеричная запись
    int c = 0b1100100;              // двоичная запись
    int d = 0x64;                   // шестнадцатеричная запись

    unsigned int e = 100U;          // беззнаковый
    long int f = 100L;              // long
    unsigned long int g = 100UL;    // unsigned long
    long long int h = 100LL;        // long long
    unsigned long long int i = 100ULL; // unsigned long long

    std::cout << a << std::endl;
    std::cout << b << std::endl;
    std::cout << c << std::endl;
    std::cout << d << std::endl;
    std::cout << e << std::endl;
    std::cout << f << std::endl;
    std::cout << g << std::endl;
    std::cout << h << std::endl;
    std::cout << i << std::endl;

    return 0;
}
```

Первые четыре литерала задают одно и то же число `100`, но записанное в разных системах счисления.

`100` — десятичная запись.

`0144` — восьмеричная запись.

`0b1100100` — двоичная запись.

`0x64` — шестнадцатеричная запись.

Далее показаны разные суффиксы:

`100U` — беззнаковый литерал.

`100L` — литерал `long`.

`100UL` — беззнаковый `long`.

`100LL` — `long long`.

`100ULL` — беззнаковый `long long`.

### Ответ

Программа использует десятичные, восьмеричные, двоичные и шестнадцатеричные литералы, а также суффиксы `U`, `L`, `UL`, `LL` и `ULL`.

### Задание 3 **(2)**
*Объясните работу фрагмента программы на С++. В ходе объяснения следует использовать таблицу кодов символов.*
```cpp
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

### Решение

По лекции C++ не различает символьные и числовые типы: символ связан со своим числовым кодом.

По таблице кодов из лекции символ `'a'` имеет код:

`01100001`

В десятичной записи это:

`97`

После выполнения:

```cpp
char a = 'a';
```

в `a` находится символ `'a'`, то есть код `97`.

Далее выполняется:

```cpp
a = a + 10;
```

К коду символа прибавляется 10:

`97 + 10 = 107`

По таблице кодов число `107` соответствует символу:

`'k'`

Поэтому первая команда:

```cpp
std::cout << a;
```

выведет:

`k`

Далее:

```cpp
a = a + 250;
```

Сейчас в `a` находится код `107`.

Получаем:

`107 + 250 = 357`

По лекции `char` имеет длину 1 байт, то есть 8 бит.

Для 8 бит количество возможных комбинаций:

`2^8 = 256`

При выходе за границу диапазона по правилу из лекции берётся остаток по модулю `2^n`.

В данном случае:

`357 mod 256 = 101`

Можно посчитать:

`357 - 256 = 101`

Следовательно, после переполнения в `a` будет код:

`101`

По таблице кодов символов код `101` соответствует символу:

`'e'`

Второй `std::cout` выведет:

`e`

Так как между двумя операциями вывода нет пробела, итоговый вывод:

`ke`

### Ответ

Программа выведет:

```text
ke
```

Сначала `'a'` имеет код `97`.

`97 + 10 = 107` — это символ `'k'`.

Затем:

`107 + 250 = 357`

Из-за длины `char` в 8 бит:

`357 mod 256 = 101`

Код `101` соответствует символу `'e'`.

### Задание 4 **(2)**

*Перепишите программу из предыдущего задания на Python, используя функции* **chr** и **ord**.
*Почему ее вывод отличается от вывода программы на С++?*

### Решение

По лекции Python работает с кодировкой Unicode.

Для получения числового кода символа используется функция:

`ord()`

Для получения символа по его коду используется:

`chr()`

Исходный символ:

`'a'`

Программа на Python:

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')
a = chr(ord(a) + 250)
print(a)
```

Разберём её.

Сначала:

```python
a = 'a'
```

Код символа `'a'` равен 97.

Выражение:

```python
ord(a)
```

даёт:

`97`

Прибавляем 10:

`97 + 10 = 107`

Получаем символ с кодом 107:

```python
chr(107)
```

Это символ:

`'k'`

Далее к коду `'k'` прибавляется 250:

`107 + 250 = 357`

В Python строка работает с Unicode, поэтому значение не ограничивается одним байтом, как `char` в рассмотренном примере C++.

Функция:

```python
chr(357)
```

возвращает символ Unicode с кодом 357.

Поэтому здесь не происходит перехода:

`357 -> 101`

как в C++.

### Ответ

Программа:

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')
a = chr(ord(a) + 250)
print(a)
```

Вывод отличается потому, что в рассмотренной программе C++ значение хранится в `char` длиной 1 байт, поэтому при выходе за диапазон происходит переход по модулю `256`.

В Python используются Unicode и функции `ord()` и `chr()`, поэтому код `357` используется непосредственно.

### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```cpp
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```

### Решение

По лекции распространённая длина типа `short` — 2 байта.

2 байта:

`2 * 8 = 16 бит`

Так как используется `unsigned short`, тип является беззнаковым.

По лекции диапазон беззнакового типа длиной `n` бит:

`[0; 2^n - 1]`

При `n = 16`:

`[0; 2^16 - 1]`

`2^16 = 65536`

Следовательно:

`[0; 65535]`

Начальное значение:

`x = 40000`

Оно находится внутри диапазона.

---

#### Вычисление y

Выполняется:

```cpp
unsigned short y = x + x;
```

Подставляем `x = 40000`:

`40000 + 40000 = 80000`

Но максимальное значение равно:

`65535`

Поэтому произошло переполнение.

По правилу из лекции берём остаток по модулю `2^16`, то есть по модулю `65536`:

`80000 mod 65536`

Вычитаем 65536:

`80000 - 65536 = 14464`

Получаем:

`y = 14464`

Далее:

```cpp
y = y - x;
```

Подставляем значения:

`y = 14464 - 40000`

Получаем:

`-25536`

Но `unsigned short` является беззнаковым, поэтому снова рассматриваем результат по модулю 65536:

`-25536 + 65536 = 40000`

Получаем:

`y = 40000`

То есть вернулось исходное значение `x`.

Именно поэтому:

`x + x - x = x`

---

#### Вычисление z

Теперь:

```cpp
unsigned short z = x * 2;
```

Получаем:

`40000 * 2 = 80000`

Снова произошло переполнение:

`80000 - 65536 = 14464`

Следовательно:

`z = 14464`

Теперь выполняется:

```cpp
z = z / 2;
```

Получаем:

`14464 / 2 = 7232`

Следовательно:

`z = 7232`

Это не равно исходному значению:

`7232 != 40000`

Причина состоит в том, что после умножения произошёл выход за диапазон и в `z` сохранилось уже не `80000`, а:

`14464`

После этого программа делит на 2 именно `14464`:

`14464 / 2 = 7232`

Поэтому исходное значение восстановить уже нельзя.

### Ответ

Программа выведет:

```text
40000 7232
```

Для `y`:

`40000 + 40000 = 80000`

`80000 mod 65536 = 14464`

`14464 - 40000 = -25536`

`-25536 + 65536 = 40000`

Поэтому:

`x + x - x = x`

Для `z`:

`40000 * 2 = 80000`

`80000 mod 65536 = 14464`

`14464 / 2 = 7232`

Поэтому:

`(x * 2) / 2 != x`

### Задание 6 **(2)**

*Объясните работу фрагмента программы на С++. Если имеет место переполнение, 
то требуется найти точный ответ до запуска программы, а только потом сверить его с выводом.
В отчете надо привести вычисления, приводящие к ответу.*
```cpp
std::cout << 2000000000 + 1000000000 << std::endl;
std::cout << 2000000000U + 1000000000U << std::endl;
std::cout << 2500000000U + 2500000000U << std::endl;
std::cout << 2500000000LL + 2500000000LL << std::endl;
std::cout << 20000U * 200000U << std::endl;
std::cout << 200000U * 200000U << std::endl;
```

### Решение

По лекции суффикс `U` обозначает беззнаковый литерал, а `LL` — литерал типа `long long`.

Для 32-битного типа:

`2^32 = 4294967296`

Диапазон беззнакового 32-битного типа:

`0 ... 4294967295`

Диапазон знакового 32-битного типа:

`-2147483648 ... 2147483647`

При переполнении используем правило из лекции — результат рассматривается по модулю `2^n`.

---

#### 1. `2000000000 + 1000000000`

Складываем:

`2000000000 + 1000000000 = 3000000000`

Для знакового 32-битного числа максимум:

`2147483647`

Число `3000000000` больше максимума, поэтому имеет место переполнение.

Вычитаем `2^32`:

`3000000000 - 4294967296 = -1294967296`

Получаем:

`-1294967296`

---

#### 2. `2000000000U + 1000000000U`

Суффикс `U` означает беззнаковый тип.

Вычисляем:

`2000000000 + 1000000000 = 3000000000`
Максимум беззнакового 32-битного числа:

`4294967295`

Проверяем:

`3000000000 < 4294967295`

Переполнения нет.

Результат:

`3000000000`

---

#### 3. `2500000000U + 2500000000U`

Складываем:

`2500000000 + 2500000000 = 5000000000`

Это больше:

`4294967295`

Значит, произошло переполнение.

Вычитаем `2^32`:

`5000000000 - 4294967296 = 705032704`

Получаем:

`705032704`

---

#### 4. `2500000000LL + 2500000000LL`

Суффикс `LL` задаёт тип `long long`.

По лекции распространённая длина `long long` — 8 байт.

8 байт = 64 бита.

Складываем:

`2500000000 + 2500000000 = 5000000000`

Это число помещается в рассматриваемый `long long`.

Поэтому переполнения нет.

Получаем:

`5000000000`

---

#### 5. `20000U * 200000U`

Оба литерала беззнаковые.

Выполняем умножение:

`20000 * 200000 = 4000000000`

Максимум:

`4294967295`

Проверяем:

`4000000000 < 4294967295`

Следовательно, переполнения нет.

Результат:

`4000000000`

---

#### 6. `200000U * 200000U`

Выполняем умножение:

`200000 * 200000 = 40000000000`

Число больше максимального значения:

`40000000000 > 4294967295`

Произошло переполнение.

Нужно найти остаток по модулю:

`2^32 = 4294967296`

Вычитаем `4294967296`, пока не получим число из диапазона.

`40000000000 - 9 * 4294967296`

Сначала:

`9 * 4294967296 = 38654705664`

Теперь:

`40000000000 - 38654705664 = 1345294336`

Получаем:

`1345294336`

### Ответ

Программа выводит:

```text
-1294967296
3000000000
705032704
5000000000
4000000000
1345294336
```

### Задание 7 **(2)**

*Напишите программу на Python умножающую введенное число на 1000. В программе 
можно использовать только операторы сдвига и сложения. Циклы использовать нельзя. Из функций
можно использовать только* **input** *и* **print** *для ввода и вывода.*
```python
x = int(input())
y = ...
print(y)
```

### Решение

По лекции сдвиг числа влево на `n` разрядов соответствует умножению на `2^n`.

То есть:

`x << n = x * 2^n`

Нужно получить:

`x * 1000`

Разложим 1000 по степеням двойки:

`1000 = 512 + 256 + 128 + 64 + 32 + 8`

Проверим:

`512 + 256 = 768`

`768 + 128 = 896`

`896 + 64 = 960`

`960 + 32 = 992`

`992 + 8 = 1000`

Теперь представим каждое число как степень двойки:

`512 = 2^9`

`256 = 2^8`

`128 = 2^7`

`64 = 2^6`

`32 = 2^5`

`8 = 2^3`

Следовательно:

`1000 = 2^9 + 2^8 + 2^7 + 2^6 + 2^5 + 2^3`

Умножаем всё на `x`:

`1000x = x*2^9 + x*2^8 + x*2^7 + x*2^6 + x*2^5 + x*2^3`

Каждое умножение на степень двойки заменяем сдвигом:

`1000x = (x << 9) + (x << 8) + (x << 7) + (x << 6) + (x << 5) + (x << 3)`

Получаем программу:

```python
x = int(input())
y = (x << 9) + (x << 8) + (x << 7) + (x << 6) + (x << 5) + (x << 3)
print(y)
```

Здесь не используется оператор умножения и не используются циклы.

### Ответ

```python
x = int(input())
y = (x << 9) + (x << 8) + (x << 7) + (x << 6) + (x << 5) + (x << 3)
print(y)
```

### Задание 8 **(2)**

*Найдите результаты вычисления следующих выражений без использования компьютера

По лекции:

- `&` — побитовая конъюнкция;
- `^` — исключающее ИЛИ;
- `~` — отрицание всех битов;
- `<<` — сдвиг влево;
- `>>` — сдвиг вправо.

---

#### 1. `(1000 & 100) << 10`

Запишем числа в двоичном виде:

`1000 = 1111101000`

`100 = 0001100100`

Выполняем `&`.

Единица получается только там, где в обоих числах стоит единица:

```text
1111101000
0001100100
----------
0001100000
```

Получили:

`0001100000`

Это число:

`64 + 32 = 96`

Теперь выполняем:

###  Задание 9 **(2)**
*Напишите программу на языке С++ для умножения заданного целого числа на* $-1$. *В программе можно использовать только сложение и битовые
операции. Условия, циклы, библиотечные функции использовать нельзя.*

### Решение

В лекции в разделе «Двоичный дополнительный код» приведена формула:

`-x = ~x + 1`

Здесь:

`~x`

означает инверсию всех битов числа `x`.

После инверсии необходимо прибавить `1`.

Таким образом, чтобы умножить заданное число на `-1`, не нужно использовать оператор умножения.

Достаточно выполнить:

```cpp
x = ~x + 1;
```

Например, программа:

```cpp
#include <iostream>

int main() {
    int x;
    std::cin >> x;

    x = ~x + 1;

    std::cout << x << std::endl;

    return 0;
}
```

Разберём основную строку:

```cpp
x = ~x + 1;
```

Сначала выполняется:

`~x`

Все биты числа `x` заменяются на противоположные:

- `0` становится `1`;
- `1` становится `0`.

После этого прибавляется:

`1`

По формуле из лекции:

`-x = ~x + 1`

поэтому полученное значение равно исходному числу, умноженному на `-1`.

Например, если:

`x = 5`

то после:

`~x + 1`

получается:

`-5`

Если:

`x = -5`

то результатом будет:

`5`

### Ответ

```cpp
#include <iostream>

int main() {
    int x;
    std::cin >> x;

    x = ~x + 1;

    std::cout << x << std::endl;

    return 0;
}
```

Основная формула:

`-x = ~x + 1`
