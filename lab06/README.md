* ```const auto Pi = acos(x) * 2;```

#### Решение

В лекции 6 в разделе «Именованные константы» рассматриваются два вида констант в C++:

1. **Константы этапа трансляции** — константы, значения которых вычисляются во время компиляции программы.
2. **Константные объекты** — объекты, значения которых нельзя изменять обычным присваиванием после инициализации.

Для объявления констант времени компиляции используется ключевое слово `constexpr`.

Ключевое слово `const` указывает на неизменяемость объекта, однако само по себе не гарантирует, что значение будет вычислено на этапе трансляции.

Рассмотрим каждый вариант объявления `Pi`.

#### Вариант 1

```cpp
const auto Pi = acos(0) * 2;
```

Полный текст программы:

```cpp
#include <iostream>
#include <cmath>

int main() {
    double x = 0;
    const auto Pi = acos(0) * 2;
    std::cout << Pi << std::endl;
    return 0;
}
```

**Результат:** программа успешно компилируется и выводит приблизительно:

```text
3.14159
```

**Объяснение:**

- `const` запрещает изменять значение `Pi` после инициализации.
- `auto` автоматически определяет тип переменной по результату выражения.
- `acos(0)` вычисляет арккосинус нуля.
- Умножение результата на 2 позволяет получить число π.
- В выражении используется литерал `0`, поэтому результат не зависит от изменяемой переменной.
- Однако использование `const` не гарантирует вычисления выражения на этапе трансляции.

Таким образом, `Pi` является константным объектом. Обязательное вычисление его значения на этапе трансляции не гарантируется.

#### Вариант 2

```cpp
constexpr auto Pi = std::acos(0) * 2;
```

Полный текст программы:

```cpp
#include <iostream>
#include <cmath>

int main() {
    double x = 0;
    constexpr auto Pi = std::acos(0) * 2;
    std::cout << Pi << std::endl;
    return 0;
}
```

**Результат:** возможность успешной компиляции зависит от компилятора и поддержки вычисления `std::acos` во время компиляции.

**Объяснение:**

- `constexpr` требует, чтобы значение константы можно было вычислить на этапе трансляции.
- `std::acos(0)` вычисляет арккосинус нуля.
- Аргументом функции является литерал `0`, значение которого известно заранее.
- Однако известный аргумент не означает, что любую функцию можно вычислять на этапе трансляции.
- Для успешной компиляции необходимо, чтобы вычисление `std::acos(0)` допускалось в константном выражении.

Если компилятор поддерживает такое вычисление, программа успешно компилируется и выводит:

```text
3.14159
```

Если не поддерживает, возникает ошибка компиляции.

Таким образом, при успешной компиляции `Pi` является константой этапа трансляции, поскольку объявлена с использованием `constexpr`.

#### Вариант 3

```cpp
const auto Pi = acos(x) * 2;
```

Полный текст программы:

```cpp
#include <iostream>
#include <cmath>
```

**Результат:** программа успешно компилируется и выводит приблизительно:

```text
3.14159
```

**Объяснение:**

- Переменная `x` объявлена с типом `double` и инициализирована значением `0`.
- `acos(x)` вычисляет арккосинус значения переменной `x`.
- Результат умножается на 2 и присваивается `Pi`.
- `const` запрещает изменять значение `Pi` после инициализации.
- Переменная `x` не объявлена как `constexpr`, поэтому её значение не является константой этапа трансляции.
- Значение `Pi` определяется при выполнении программы.

Следовательно, `Pi` является константным объектом
но не константой этапа трансляции.

#### Вариант 4

```cpp
constexpr auto Pi = std::acos(x) * 2;
```

Полный текст программы:

```cpp
#include <iostream>
#include <cmath>

int main() {
    double x = 0;
    constexpr auto Pi = std::acos(x) * 2;
    std::cout << Pi << std::endl;
    return 0;
}
```

**Результат:** программа не компилируется.

**Объяснение:**

- `constexpr` требует вычисления значения на этапе трансляции.
- В выражении `std::acos(x) * 2` используется переменная `x`.
- Переменная `x` объявлена как обычная переменная типа `double`.
- Несмотря на то что `x` инициализирована нулём, она не является константой этапа трансляции.
- Следовательно, выражение с использованием `x` не удовлетворяет требованиям `constexpr`.

Компилятор сообщает об ошибке, поскольку значение `x` нельзя использовать как константное выражение.

Таким образом, четвёртый вариант некорректен.

#### Сравнение вариантов

| № | Объявление | Компиляция | Константа этапа трансляции |
|---|---|---|---|
| 1 | `const auto Pi = acos(0) * 2;` | Успешно | Не гарантируется |
| 2 | `constexpr auto Pi = std::acos(0) * 2;` | Зависит от поддержки `std::acos` | Да, если компиляция успешна |
| 3 | `const auto Pi = acos(x) * 2;` | Успешно | Нет |
| 4 | `constexpr auto Pi = std::acos(x) * 2;` | Ошибка | Нет |

`constexpr` используется для объявления констант этапа трансляции. При этом выражение инициализации должно допускать вычисление во время компиляции.

В третьем варианте объявляется константный объект, значение которого определяется при выполнении программы.

### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

#### Решение

В данной программе используются два вложенных блока, внутри которых объявляются переменные с одинаковыми именами `x` и `y`, но с разными типами данных.

В первом блоке переменные имеют тип `int`, а во втором — тип `double`.

Для определения необходимости вложенных фигурных скобок рассмотрим работу программы и правила области видимости переменных в C++.

#### 1. Проверка работы программы

Программа состоит из двух независимых блоков.

**Первый блок:**

```cpp
{
    int x, y;
    std::cin >> x >> y;
    std::cout << x+y << std::endl;
}
```

В этом блоке:

1. Объявляются две переменные `x` и `y` типа `int`.
2. Оператор `std::cin >> x >> y` считывает два целых числа.
3. Выражение `x+y` вычисляет сумму введённых чисел.
4. Оператор `std::cout` выводит полученную сумму.
5. После выполнения последнего оператора происходит выход из блока.

Например, при вводе:

```text
5 7
```

Программа выведет:

```text
12
```

После выхода из первого блока переменные `x` и `y`, объявленные внутри него, прекращают своё существование.

**Второй блок:**

```cpp
{
    double x, y;
    std::cin >> x >> y;
    std::cout << x+y << std::endl;
}
```

В этом блоке:

1. Объявляются две новые переменные `x` и `y` типа `double`.
2. Оператор `std::cin >> x >> y` считывает два вещественных числа.
3. Выражение `x+y` вычисляет сумму введённых значений.
4. Оператор `std::cout` выводит результат.
5. После завершения блока переменные `x` и `y` удаляются.

Например, при вводе:

```text
2.5 3.7
```

Программа выведет:

```text
6.2
```

**Пример полного выполнения программы:**

Входные данные:

```text
5 7
2.5 3.7
```

Выходные данные:

```text
12
6.2
```

Таким образом, программа последовательно вычисляет сумму двух целых чисел и сумму двух вещественных чисел.

#### 2. Область видимости переменных

В лекции 6 в разделе «Работа с переменными в C++» рассматривается понятие области видимости переменной.

**Область видимости переменной** — это фрагмент программы, в котором переменная доступна для обращения.

Согласно лекции:

- Переменные могут объявляться в произвольном месте программы.
- Область видимости переменной начинается с её объявления.
- Область видимости заканчивается при выходе из блока, в котором переменная была объявлена.
- Формально переменная удаляется при выходе из блока.
- Повторное объявление переменной с одинаковым именем в пределах одного блока запрещено.
- Во вложенном блоке допускается объявление переменной с именем, которое уже используется во внешнем блоке.

В рассматриваемой программе фигурные скобки создают два отдельных блока внутри функции `main()`.

В первом блоке объявляются переменные:

```cpp
int x, y;
```

Эти переменные существуют только в пределах первого блока.

После закрывающей фигурной скобки `}` первый блок завершается, и переменные `x` и `y` выходят из области видимости.

Во втором блоке объявляются новые переменные:

```cpp
double x, y;
```

Хотя имена переменных совпадают с именами из первого блока, конфликта не возникает, поскольку объявления находятся в разных областях видимости.

Следовательно, использование одинаковых имён `x` и `y` в данном случае допустимо.

#### 3. Что произойдёт, если убрать вложенные фигурные скобки?

Рассмотрим программу без дополнительных блоков:

```cpp
#include <iostream>

int main() {
    int x, y;
    std::cin >> x >> y;
    std::cout << x+y << std::endl;

    double x, y;
    std::cin >> x >> y;
    std::cout << x+y << std::endl;

    return 0;
}
```

**Результат:** программа не скомпилируется.

Причина заключается в повторном объявлении переменных `x` и `y` в одной области видимости.

Сначала выполняется объявление:

```cpp
int x, y;
```

После этого выполняется повторное


ти, благодаря чему переменные `x` и `y` могут объявляться повторно с другим типом данных.

После завершения первого блока переменные типа `int` удаляются, поэтому во втором блоке можно объявить новые переменные `x` и `y` типа `double`.

Если удалить вложенные фигурные скобки без изменения остальных строк программы, возникнет ошибка компиляции из-за повторного объявления переменных в одной области видимости.

При этом фигурные скобки не являются обязательными для самого вычисления сумм. Программу можно переписать без дополнительных блоков, если использовать разные имена переменных.

**Итоговый ответ:** в исходной программе вложенные фигурные скобки нужны, поскольку они разделяют области видимости переменных и позволяют повторно использовать имена `x` и `y` с разными типами. Без этих скобок исходный код не скомпилируется. Однако при переименовании переменных программа может работать и без вложенных блоков. объявлени


е:

```cpp
double x, y;
```

Однако переменные `x` и `y`, объявленные ранее, продолжают существовать до завершения функции `main()`.

Поэтому компилятор обнаружит конфликт имён.

При этом различие типов `int` и `double` не позволяет повторно объявлять переменные с одинаковыми именами в одном блоке.

Таким образом, если убрать вложенные фигурные скобки и оставить остальные строки программы без изменений, возникнет ошибка компиляции.

#### 4. Почему с фигурными скобками ошибки нет?

В исходной программе каждый набор переменных находится в собственной области видимости.

Структура программы выглядит следующим образом:

```text
main()
│
├── Первый блок
│   ├── int x
│   ├── int y
│   ├── Ввод целых чисел
│   └── Вывод суммы
│
├── Второй блок
│   ├── double x
│   ├── double y
│   ├── Ввод вещественных чисел
│   └── Вывод суммы
│
└── return 0
```

Первый блок полностью завершается до начала второго.

Следовательно:

1. При входе в первый блок создаются переменные `x` и `y` типа `int`.
2. После выполнения операций происходит выход из первого блока.
3. Переменные первого блока удаляются.
4. При входе во второй блок создаются новые переменные `x` и `y` типа `double`.
5. Новые переменные не конфликтуют с предыдущими, поскольку предыдущие уже вышли из области видимости.
6. После завершения второго блока его переменные также удаляются.

Таким образом, фигурные скобки позволяют независимо использовать одинаковые имена переменных в разных частях программы.

#### 5. Можно ли написать программу без вложенных фигурных скобок?

Да, можно, но для этого необходимо изменить имена переменных во втором блоке.

Например:

```cpp
#include <iostream>

int main() {
    int x, y;
    std::cin >> x >> y;
    std::cout << x+y << std::endl;

    double a, b;
    std::cin >> a >> b;
    std::cout << a+b << std::endl;

    return 0;
}
```

В этом варианте используются четыре переменные:

- `x` и `y` типа `int`;
- `a` и `b` типа `double`.

Все переменные имеют разные имена, поэтому конфликтов при объявлении не возникает.

Программа успешно компилируется и выполняет те же вычисления, что и исходная.

Например, при вводе:

```text
5 7
2.5 3.7
```

Результат:

```text
12
6.2
```

Однако в этом случае все четыре переменные остаются в области видимости до завершения функции `main()`.

В исходном варианте переменные существуют только внутри соответствующих блоков.

#### 6. Сравнение вариантов

| Критерий | С вложенными скобками | Без вложенных скобок |
|---|---|---|
| Объявление `int x, y` | Допустимо | Допустимо |
| Повторное объявление `double x, y` | Допустимо в отдельном блоке | Ошибка компиляции |
| Область видимости | Ограничена соответствующим блоком | Вся оставшаяся часть функции |
| Время жизни переменных | До завершения соответствующего блока | До завершения функции |
| Возможность использовать одинаковые имена | Да | Нет, в одном блоке |
| Успешная компиляция исходного кода | Да | Нет |
| Возможность исправления | Не требуется | Необходимо переименовать переменные или изменить структуру программы |

#### 7. Связь с материалами лекции

В лекции 6 рассматривается правило, согласно которому повторное объявление переменной в пределах одного блока запрещено.

Также объясняется, что вложенный блок может содержать объявление переменной с таким же именем, как во внешнем блоке.

В таком случае внешняя переменная не удаляется, а временно вытесняется из области видимости.

В данной программе ситуация несколько отличается: блоки расположены последовательно, а не один внутри другого.

Поэтому переменные первого блока не вытесняются переменными второго блока. Они уже прекращают существование к моменту начала второго блока.

Именно разделение программы на самостоятельные блоки позволяет повторно использовать имена `x` и `y` без возникновения ошибок.

Фигурные скобки создают отдельные области видимости, благодаря чему переменные `x` и `y` могут объявляться повторно с другим типом данных.

После завершения первого блока переменные типа `int` удаляются, поэтому во втором блоке можно объявить новые переменные `x` и `y` типа `double`.

Если удалить вложенные фигурные скобки без изменения остальных строк программы, возникнет ошибка компиляции из-за повторного объявления переменных в одной области видимости.

При этом фигурные скобки не являются обязательными для самого вычисления сумм. Программу можно переписать без дополнительных блоков, если использовать разные имена переменных.

**Итоговый ответ:** в исходной программе вложенные фигурные скобки нужны, поскольку они разделяют области видимости переменных и позволяют повторно использовать имена `x` и `y` с разными типами. Без этих скобок исходный код не скомпилируется. Однако при переименовании переменных программа может работать и без вложенных блоков.

#### Решение

В данном фрагменте программы используются два вложенных цикла `for`, в которых объявляются переменные с одинаковым именем `i`.

Основная особенность программы заключается в том, что переменная `i` внутреннего цикла имеет собственную область видимости и временно вытесняет из неё переменную `i` внешнего цикла.

Для определения результата необходимо рассмотреть области видимости переменных и последовательно выполнить все итерации циклов.

#### 1. Области видимости переменных

В лекции 6 в разделе «Работа с переменными в C++» рассматриваются следующие правила:

1. Переменные могут объявляться в произвольном месте программы.
2. Область видимости переменной начинается с её объявления и заканчивается выходом из блока, в котором она объявлена.
3. Цикл `for` создаёт собственную область видимости.
4. Переменные, объявленные в заголовке цикла `for`, действуют до завершения этого цикла.
5. Во вложенном блоке допускается объявление переменной с тем же именем, что и во внешнем блоке.
6. В таком случае внешняя переменная временно вытесняется из области видимости, но не удаляется.
7. После завершения вложенного блока внешняя переменная снова становится доступной.

В рассматриваемой программе объявляются две разные переменные с именем `i`.

**Переменная внешнего цикла:**

```cpp
for (int i = 0; i < 4; i++)
```

Эта переменная принимает значения:

```text
0, 1, 2, 3
```

Она управляет количеством повторений внешнего цикла.

Всего внешний цикл выполняется 4 раза.

**Переменная внутреннего цикла:**

```cpp
for (int i = 0; i < 3; i++)
```

Это новая переменная `i`, которая существует только внутри внутреннего цикла.

Она принимает значения:

```text
0, 1, 2
```

Внутренний цикл выполняется 3 раза при каждой итерации внешнего цикла.

Несмотря на одинаковые имена, переменные `i` внешнего и внутреннего циклов являются разными переменными.

При выполнении внутреннего цикла используется его собственная переменная `i`, а внешняя временно становится недоступной по этому имени.

После завершения внутреннего цикла снова используется переменная `i` внешнего цикла.

Несмотря на практически одинаковую структуру программ, результаты различаются.

Причина заключается в особенностях работы с переменными и областями видимости в этих языках.

##### 5.1. Переменные в C++

Согласно лекции 6, в императивных языках программирования переменная представляет собой идентифицируемый участок памяти.

В C++ переменная имеет определённый тип и область видимости.

Область видимости начинается с объявления переменной и заканчивается выходом из соответствующего блока.

В C++ допускается объявление переменной с одинаковым именем во вложенном блоке.

При этом новая переменная временно вытесняет внешнюю переменную из области видимости.

В программе из задания 3 используются два объявления:

```cpp
for (int i = 0; i < 4; i++)
```

и:

```cpp
for (int i = 0; i < 3; i++)
```

В данном случае создаются две разные переменные `i`.

Первая переменная управляет внешним циклом, а вторая — внутренним.

Когда выполняется внутренний цикл, используется его собственная переменная `i`.

После завершения внутреннего цикла внутренняя переменная выходит из области видимости.

При этом внешняя переменная сохраняет своё значение.

Например, если внешний счётчик равен `3`, то после выполнения внутреннего цикла внешний счётчик по-прежнему равен `3`.

Поэтому оператор:

```cpp
s += i;
```

прибавляет значение внешнего счётчика.

В результате программа на C++ вычисляет:

```text
s = (0 + 1 + 2 + 0)
  + (0 + 1 + 2 + 1)
  + (0 + 1 + 2 + 2)
  + (0 + 1 + 2 + 3)

s = 3 + 4 + 5 + 6

s = 18
```

##### 5.2. Переменные в Python

Согласно лекции 6, в Python переменная представляет собой запись в словаре переменных.

Имя переменной является ключом, а значение хранится по ссылке.

Основные особенности работы с переменными в Python:

1. Переменная создаётся в момент присваивания.
2. Переменная представляет собой ссылку на объект данных.
3. Присваивание связывает имя переменной с определённым объектом.
4. При повторном присваивании имя может быть связано с другим объектом.
5. Цикл `for` не создаёт отдельную локальную область видимости для переменной цикла.

В рассматриваемой программе:

```python
for i in range(4):
```

переменная `i` последовательно получает значения:

```text
0, 1, 2, 3
```

Однако внутри внешнего цикла выполняется:

```python
for i in range(3):
```

Этот цикл использует то же имя `i`.

В отличие от C++, здесь не создаётся отдельная переменная `i` во вложенной области видимости.

Внутренний цикл последовательно присваивает переменной значения:

```text
0, 1, 2
```

После завершения внутреннего цикла значение `i` остаётся равным `2`.

Поэтому оператор:

```python
s += i
```

каждый раз прибавляет `2`.

В результате программа вычисляет:

```text
s = (0 + 1 + 2 + 2)
  + (0 + 1 + 2 + 2)
  + (0 + 1 + 2 + 2)
  + (0 + 1 + 2 + 2)

s = 5 + 5 + 5 + 5

s = 20
```

##### 5.3. Главное различие в областях видимости

В C++ фигурные скобки создают отдельные блоки, внутри которых могут объявляться собственные переменные.

Поэтому внутренний цикл может иметь переменную с тем же именем, что и внешний, не изменяя значение внешней переменной.

В Python тело цикла не создаёт отдельную локальную область видимости.

Поэтому использование одного имени во внешнем и внутреннем циклах приводит к последовательному изменению привязки этого имени.

Именно это различие определяет разные результаты программ.

### Задание 5 **(2)**

*Напишите свой пример программы на* **С++**, *создающий и использующий пространства имен. Программа
должна содержать не менее двух пространств имен.*

#### Решение

В C++ пространства имён (`namespace`) позволяют объединять переменные и другие объекты в отдельные группы. Благодаря этому в разных пространствах можно использовать одинаковые имена без конфликтов.

Создадим два пространства имён: `pervi` и `vtoroi`.

#### Текст программы

```cpp
#include <iostream>

namespace pervi {
    int x = 10;
    int y = 20;
}

namespace vtoroi {
    int x = 5;
    int y = 15;
}

int main() {
    std::cout << "Pervi namespace: "
              << pervi::x + pervi::y << std::endl;

    std::cout << "Vtoroi namespace: "
              << vtoroi::x + vtoroi::y << std::endl;

    using pervi::x;

    std::cout << "X from pervi: "
              << x << std::endl;

    using namespace vtoroi;

    std::cout << "Y from vtoroi: "
              << y << std::endl;

    return 0;
}
```

#### Результат выполнения

```text
Pervi namespace: 30
Vtoroi namespace: 20
X from pervi: 10
Y from vtoroi: 15
```

#### Объяснение

В программе созданы два пространства имён:

- `pervi` содержит переменные `x = 10` и `y = 20`.
- `vtoroi` содержит переменные `x = 5` и `y = 15`.

Несмотря на одинаковые имена переменных, ошибок не возникает, поскольку они находятся в разных пространствах имён.

Оператор `::` позволяет обращаться к переменным конкретного пространства:

```cpp
pervi::x + pervi::y   // 10 + 20 = 30
vtoroi::x + vtoroi::y // 5 + 15 = 20
```

Команда `using pervi::x;` позволяет использовать переменную `x` из пространства `pervi` без указания `pervi::`.

Команда `using namespace vtoroi;` позволяет обращаться к именам из пространства `vtoroi` без обязательного указания `vtoroi::`.

Поэтому программа дополнительно выводит `x = 10` и `y = 15`.

Программа показывает, что пространства имён позволяют использовать одинаковые имена переменных без конфликтов. Также рассмотрено обращение к переменным с помощью оператора `::` и ключевого слова `using`.


### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

#### Решение

В данной программе выполняется один миллион обменов значений двух строк длиной по 100000 символов.

Необходимо сравнить три способа обмена:

1. Исходный способ с копированием строк.
2. Обмен с помощью функции `std::swap`.
3. Исправленный способ с временной переменной и перемещением через `std::move`.

Главная задача — выяснить, почему копирование больших строк занимает больше времени, чем обмен или перемещение их внутренних ресурсов.

#### 1. Как работает исходная программа

```cpp
std::string a(100000, 'a');
std::string b(100000, 'b');
```

Здесь создаются две строки.

Первая содержит 100000 символов `a`, вторая — 100000 символов `b`.

```text
a = "aaaaaaaa..." (100000 символов)
b = "bbbbbbbb..." (100000 символов)
```

Затем выполняется цикл:

```cpp
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
```

Разберём одну итерацию.

**Шаг 1. Создание временной строки**

```cpp
std::string c(a);
```

Создаётся строка `c`, в которую копируются символы строки `a`.

Получаем:

```text
a = "aaaa..."
b = "bbbb..."
c = "aaaa..."
```

**Шаг 2. Присваивание a = b**

```cpp
a = b;
```

В строку `a` копируется содержимое строки `b`.

```text
a = "bbbb..."
b = "bbbb..."
c = "aaaa..."
```

**Шаг 3. Присваивание b = c**

```cpp
b = c;
```

В строку `b` копируется содержимое временной строки `c`.

```text
a = "bbbb..."
b = "aaaa..."
c = "aaaa..."
```

Теперь значения `a` и `b` поменялись местами.

После завершения итерации временная строка `c` уничтожается.

При следующей итерации всё повторяется.

#### 2. Почему исходный вариант медленный?

Проблема заключается в многократном копировании символов.

За одну итерацию:

```cpp
std::string c(a); // Копирование 100000 символов
a = b;            // Копирование 100000 символов
b = c;            // Копирование 100000 символов
```

Приблизительный объём копирования:

```text
100000 * 3 = 300000 символов за итерацию
```

За миллион итераций:

```text
300000 * 1000000 = 300000000000 символов
```

То есть программа выполняет копирование примерно 300 миллиардов символов.

Кроме того, временная строка создаётся и уничтожается на каждой итерации. Это также может требовать выделения и освобождения памяти.

Следовательно, исходная программа работает медленно из-за большого количества ненужных операций копирования.

#### 3. Программа для измерения времени исходного варианта

```cpp
#include <iostream>
#include <string>
#include <chrono>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    auto start = std::chrono::steady_clock::now();

    for (int i = 0; i < 1000000; i++) {
        std::string c(a);
        a = b;
        b = c;
    }

    auto finish = std::chrono::steady_clock::now();

    std::chrono::duration<double> time = finish - start;

    std::cout << a[0] << b[0] << std::endl;
    std::cout << "Time: " << time.count() << " s" << std::endl;

    return 0;
}
```

Для измерения времени используется библиотека `<chrono>`.

Команда:

```cpp
auto start = std::chrono::steady_clock::now();
```

запоминает время перед циклом.

Команда:

```cpp
auto finish = std::chrono::steady_clock::now();
```

запоминает время после цикла.

Разность:

```cpp
finish - start
```

показывает продолжительность выполнения цикла.

Команда:

```cpp
time.count()
```

возвращает время в секундах.

Результат программы имеет вид:

```text
ab
Time: ... s
```

Строка `ab` появляется потому, что миллион — чётное число.

После первого обмена:

```text
a = "bbbb..."
b = "aaaa..."
```

После второго:

```text
a = "aaaa..."
b = "bbbb..."
```

Таким образом, после чётного количества обменов строки возвращаются к исходному состоянию.

#### 4. Использование функции swap

Для обмена строк можно использовать `std::swap`.

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <chrono>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    auto start = std::chrono::steady_clock::now();

    for (int i = 0; i < 1000000; i++) {
        std::swap(a, b);
    }

    auto finish = std::chrono::steady_clock::now();

    std::chrono::duration<double> time = finish - start;

    std::cout << a[0] << b[0] << std::endl;
    std::cout << "Time: " << time.count() << " s" << std::endl;

    return 0;
}
```

Функция:

```cpp
std::swap(a, b);
```

меняет местами содержимое строк.

Для обычных строк `std::string` обмен может выполняться путём обмена внутренними ресурсами объектов, без копирования всех символов.

Упрощённо:

```text
До обмена:

a ---> [100000 символов 'a']
b ---> [100000 символов 'b']

После обмена:

a ---> [100000 символов 'b']
b ---> [100000 символов 'a']
```

Здесь показан принцип обмена, а не точное устройство объектов в памяти.

Поскольку не требуется копировать все 100000 символов, `std::swap` обычно работает значительно быстрее.

#### 5. Исправление исходной программы без изменения её структуры

По условию необходимо сохранить временную переменную и присваивания.

Поэтому вместо обычного копирования используем `std::move`.

Исправленный вариант:

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <chrono>

int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');

    auto start = std::chrono::steady_clock::now();

    for (int i = 0; i < 1000000; i++) {
        std::string c(std::move(a));
        a = std::move(b);
        b = std::move(c);
    }

    auto finish = std::chrono::steady_clock::now();

    std::chrono::duration<double> time = finish - start;

    std::cout << a[0] << b[0] << std::endl;
    std::cout << "Time: " << time.count() << " s" << std::endl;

    return 0;
}
```

В программе сохранена исходная последовательность действий:

```cpp
std::string c(std::move(a));
a = std::move(b);
b = std::move(c);
```

То есть:

1. Значение `a` передаётся во временную строку `c`.
2. Значение `b` передаётся строке `a`.
3. Значение `c` передаётся строке `b`.

Однако теперь вместо копирования используются операции перемещения.

#### 6. Как работает std::move?

`std::move` позволяет использовать перемещающий конструктор или перемещающий оператор присваивания.

Сам по себе `std::move` не переносит символы. Он позволяет передать объект операции, которая может забрать его внутренние ресурсы.

Рассмотрим исправленный обмен.

**Начальное состояние:**

```text
a ---> [100000 символов 'a']
b ---> [100000 символов 'b']
```

**Первая операция:**

```cpp
std::string c(std::move(a));
```

Строка `c` получает содержимое `a` путём перемещения.

Упрощённо:

```text
a ---> [пустая строка]
b ---> [100000 символов 'b']
c ---> [100000 символов 'a']
```

После перемещения объект `a` остаётся корректным, но его прежнее содержимое уже передано объекту `c`.

**Вторая операция:**

```cpp
a = std::move(b);
```

Теперь строка `a` получает содержимое строки `b`.

```text
a ---> [100000 символов 'b']
b ---> [пустая строка]
c ---> [100000 символов 'a']
```

**Третья операция:**

```cpp
b = std::move(c);
```

Строка `b` получает содержимое временной строки `c`.

```text
a ---> [100000 символов 'b']
b ---> [100000 символов 'a']
c ---> [пустая строка]
```

Значения `a` и `b` поменялись местами.

При этом длинные последовательности символов не пришлось копировать три раза.

Важно: стандарт C++ гарантирует корректное, но не обязательно пустое состояние перемещённого объекта. В данном примере это не мешает работе, поскольку каждому объекту после перемещения присваивается новое значение, прежде чем его содержимое снова используется.

#### 7. Сравнение исходного и исправленного вариантов

**Исходный код:**

```cpp
std::string c(a);
a = b;
b = c;
```

Здесь выполняется копирование строк.

**Исправленный код:**

```cpp
std::string c(std::move(a));
a = std::move(b);
b = std::move(c);
```

Здесь выполняется перемещение строк.

Главное различие:

- При копировании создаётся независимое содержимое строки, поэтому необходимо копировать символы.
- При перемещении длинной строки обычно передаются её внутренние ресурсы, поэтому копирование всех символов не требуется.

Таким образом, исправленная программа выполняет тот же обмен, но значительно эффективнее.

#### 8. Сравнение скорости работы

| Вариант программы | Способ обмена | Ожидаемая скорость |
|---|---|---|
| Исходный | Копирование строк | Медленный |
| С `std::swap` | Обмен внутренними ресурсами | Быстрый |
| С `std::move` | Перемещение ресурсов | Быстрый |

Вариант с `std::swap` обычно наиболее простой и удобный для обмена строк.

Вариант с `std::move` также позволяет избежать копирования, но сохраняет три операции исходной программы.

Конкретное время выполнения зависит от компьютера, компилятора и параметров оптимизации.

Для корректного сравнения необходимо запускать все три варианта в одинаковых условиях.

#### Вывод

В ходе выполнения задания была рассмотрена программа, которая один миллион раз обменивает значения двух строк длиной по 100000 символов.

Установлено, что исходный вариант работает медленно из-за многократного копирования символов при создании временной строки и присваивании значений.

Функция `std::swap` позволяет обменивать строки без копирования всех их символов, что значительно ускоряет выполнение программы.

Для исправления исходного варианта с сохранением временной переменной и присваиваний использована функция `std::move`.

Перемещение позволяет передавать внутренние ресурсы строк вместо копирования больших объёмов данных.

**Итог:** основная ошибка исходной программы — неэффективное копирование длинных строк. Для ускорения можно использовать `std::swap`, а для сохранения первоначальной структуры программы — `std::move`.

#### Решение

В данной программе рассматривается работа со строковыми объектами, переменными и ссылками в Python.

Согласно лекции 6, в Python переменная представляет собой имя, связанное с объектом. При присваивании переменной другого значения изменяется связь имени с объектом.

Также важно учитывать, что строки в Python являются неизменяемыми объектами. После создания строки нельзя изменить её символы непосредственно. При необходимости получить строку с другим содержимым создаётся новый строковый объект.

#### 1. Разбор первой строки

```python
a = 'Hello world'
```

Здесь строковый объект со значением `'Hello world'` связывается с именем `a`.

Схематически:

```text
a ───> 'Hello world'
```

Теперь переменная `a` ссылается на строку `'Hello world'`.

Далее выполняется:

```python
print(a, id(a))
```

Функция `print()` выводит значение строки и результат вызова `id(a)`.

Функция `id()` возвращает целое число, являющееся идентификатором объекта.

Этот идентификатор уникален среди объектов, существующих одновременно.

В реализации CPython идентификатор обычно связан с адресом объекта в памяти, но в общем случае Python не требует, чтобы `id()` обязательно возвращала адрес памяти.

Например, результат может выглядеть так:

```text
Hello world 140000001
```

Число приведено только для примера. При реальном запуске оно может быть другим.

#### 2. Присваивание b = a

Следующая команда:

```python
b = a
```

Не создаёт копию строки `'Hello world'`.

Вместо этого имя `b` связывается с тем же объектом, на который уже ссылается `a`.

Схематически:

```text
a ───┐
     ├───> 'Hello world'
b ───┘
```

Таким образом, обе переменные ссылаются на один строковый объект.

Поэтому команда:

```python
print(b, id(b))
```

выводит то же значение строки и тот же идентификатор объекта, что и первая команда `print()`.

Например:

```text
Hello world 140000001
```

На этом этапе выполняется равенство:

```python
id(a) == id(b)
```

Результат:

```text
True
```

Это означает, что обе переменные связаны с одним объектом.

#### 3. Выполнение a += ' and goodbye'

Следующая команда:

```python
a += ' and goodbye'
```

На первый взгляд кажется, что программа просто добавляет символы к существующей строке.

Однако строки в Python неизменяемы.

Поэтому обычный результат этой операции — создание новой строки, содержащей объединённые значения:

```text
'Hello world and goodbye'
```

После выполнения команды имя `a` связывается с новым строковым объектом.

При этом переменная `b` продолжает ссылаться на исходную строку.

Схематически:

```text
a ───> 'Hello world and goodbye'

b ───> 'Hello world'
```

То есть первоначальный объект не изменился.

Изменилась только связь имени `a` с объектом.

Это ключевой момент программы.

#### 4. Вывод после изменения a

Теперь выполняется:

```python
print(a, id(a))
```

Переменная `a` ссылается на новую строку.

Поэтому выводится:

```text
Hello world and goodbye 140000002
```

Здесь идентификатор отличается от первоначального, поскольку речь идёт о другом объекте.

Затем выполняется:

```python
print(b, id(b))
```

Переменная `b` по-прежнему ссылается на первоначальную строку `'Hello world'`.

Поэтому выводится:

```text
Hello world 140000001
```

Идентификатор объекта `b` остаётся прежним.

#### 5. Пример полного результата программы

```text
Hello world 140000001
Hello world 140000001
Hello world and goodbye 140000002
Hello world 140000001
```

**Важно:** конкретные числовые значения `id()` заранее неизвестны. Они зависят от выполнения программы. Существенно не само число, а совпадение или различие идентификаторов.

#### 6. В какой момент создавались строки?

Рассмотрим последовательность событий.

| Операция | Что происходит |

|---|---|
| `a = 'Hello world'` | Имя `a` связывается со строковым объектом `'Hello world'` |
| `b = a` | Имя `b` связывается с тем же объектом; копия строки не создаётся |

Следовательно, программа демонстрирует, что **присваивание имени существующей переменной не означает копирование объекта**, а изменение значения строки приводит к получению другого строкового объекта.

### Задание 8 **(2)**

*Пусть* **a** - *строковая переменная в программе на* **Python**.
*Есть ли разница между работой присваивания*
```b = a```
и
```b = a[:]```
*Напишите программу для демонстрации различий.*

#### Решение

В данном задании необходимо сравнить два способа присваивания строковой переменной:

```python
b = a
```

и:

```python
b = a[:]
```

На первый взгляд эти выражения отличаются: в первом случае выполняется обычное присваивание, а во втором используется операция получения среза строки.

Однако для строк Python результат может оказаться одинаковым не только по значению, но и по идентичности объекта.

#### 1. Первый способ: b = a

Рассмотрим программу:

```python
a = 'Hello world'
b = a

print(a)
print(b)
print(id(a))
print(id(b))
print(a is b)
```

Команда:

```python
a = 'Hello world'
```

связывает переменную `a` со строковым объектом.

Затем выполняется:

```python
b = a
```

Имя `b` связывается с тем же объектом.

Схематически:

```text
a ───┐
     ├───> 'Hello world'
b ───┘
```

Поэтому:

```python
a is b
```

возвращает:

```text
True
```

Идентификаторы объектов совпадают:

```python
id(a) == id(b)
```

Результат:

```text
True
```

Таким образом, при обычном присваивании `b = a` копирование содержимого строки не выполняется.

#### 2. Второй способ: b = a[:]

Теперь рассмотрим:

```python
a = 'Hello world'
b = a[:]

print(a)
print(b)
print(id(a))
print(id(b))
print(a is b)
```

Выражение:

```python
a[:]
```

называется полным срезом строки.

Оно означает получение всех символов строки, от первого до последнего.

Например:

```python
a = 'Hello world'
print(a[:])
```

Результат:

```text
Hello world
```

Таким образом, по значению выражение `a[:]` возвращает ту же последовательность символов.

Но возникает вопрос: создаётся ли при этом новый объект?

Поскольку строки в Python являются неизменяемыми, нет необходимости обязательно создавать новую строку с теми же символами.

Реализация Python может вернуть ссылку на исходный строковый объект.

В частности, в CPython полный срез обычной строки возвращает тот же объект.

Поэтому программа обычно выводит:

```text
Hello world
Hello world
...
...
True
```

Числовые идентификаторы здесь не приведены, поскольку они зависят от запуска программы. В CPython они будут одинаковыми.

#### 3. Программа для сравнения двух способов

```python
a = 'Hello world'

b = a
c = a[:]

print("a =", a)
print("b =", b)
print("c =", c)

print("a == b:", a == b)
print("a == c:", a == c)

print("a is b:", a is b)
print("a is c:", a is c)

print("id(a):", id(a))
print("id(b):", id(b))
print("id(c):", id(c))
```

**Результат выполнения в CPython:**

```text
a = Hello world
b = Hello world
c = Hello world
a == b: True
a == c: True
a is b: True
a is c: True
id(a): ...
id(b): ...
id(c): ...
```

Все три идентификатора совпадают.

Это означает, что переменные `a`, `b` и `c` ссылаются на один строковый объект.

#### 4. Почему Python может не создавать копию?

Строки в Python неизменяемы.

Это означает, что после создания строкового объекта нельзя изменить его отдельные символы.

Например, следующая команда вызовет ошибку:

```python
a = 'Hello'
a[0] = 'Y'
```

Ошибка возникает потому, что строка не поддерживает изменение символов по индексу.

Следовательно, если две переменные ссылаются на одну строку, это не создаёт опасности случайного изменения её содержимого через одну из переменных.

Поэтому при выполнении полного среза:

```python
a[:]
```

Python может повторно использовать уже существующий объект.

Это позволяет избежать лишнего копирования символов.

#### 5. Что произойдёт при изменении значения a?

Рассмотрим программу:

```python
a = 'Hello world'

b = a
c = a[:]

a += ' and goodbye'

print("a =", a)
print("b =", b)
print("c =", c)
```

Результат:

```text
a = Hello world and goodbye
b = Hello world
c = Hello world
```

Почему так происходит?

Первоначально все три переменные ссылаются на строку `'Hello world'`.

Затем выполняется:

```python
a += ' and goodbye'
```
Поскольку строки неизменяемы, получается новый строковый объект.

Имя `a` связывается с новой строкой.

Переменные `b` и `c` продолжают ссылаться на прежний объект.

Схематически:

```text
До изменения:

a ───┐
b ───┼───> 'Hello world'
c ───┘

После изменения:

a ───────> 'Hello world and goodbye'

b ───┐
     ├───> 'Hello world'
c ───┘
```

Таким образом, оба способа присваивания приводят к одинаковому поведению при последующем изменении значения переменной `a`.

#### 6. В чём всё-таки различие между операциями?

Различие существует на уровне выполняемых действий.

**Обычное присваивание:**

```python
b = a
```

Связывает имя `b` с объектом, на который указывает `a`.

**Присваивание с использованием полного среза:**

```python
b = a[:]
```

Сначала вычисляет выражение полного среза строки, а затем связывает имя `b` с полученным результатом.

Однако для неизменяемых строк Python создание отдельного объекта не требуется.

Поэтому полный срез может возвращать тот же объект.

| Критерий | `b = a` | `b = a[:]` |
|---|---|---|
| Операция | Обычное присваивание | Получение полного среза и присваивание |
| Значение `b` | Совпадает с `a` | Совпадает с `a` |
| Создание копии строки | Нет | Не гарантируется |
| Результат `a is b` в CPython для обычной строки | `True` | `True` |
| Изменение значения `a` через новое присваивание | Не меняет значение `b` | Не меняет значение `b` |

Важно не путать строки со списками.

Например, для списка:

```python
a = [1, 2, 3]
b = a[:]
```

полный срез создаёт новый список.

Но для строки:

```python
a = 'Hello'
b = a[:]
```

новый строковый объект создавать необязательно.

#### Вывод

В ходе выполнения задания были рассмотрены два способа присваивания строковой переменной в Python: `b = a` и `b = a[:]`.

Установлено, что обычное присваивание связывает имя `b` с существующим строковым объектом.

Выражение `a[:]` получает полный срез строки, но поскольку строки неизменяемы, Python может использовать уже существующий объект.

Поэтому в CPython оба варианта приводят к тому, что переменные `a` и `b` ссылаются на один объект.

При последующем присваивании переменной `a` новой строки значение переменной `b` не изменяется.

**Итог:** разница между выражениями заключается в способе вычисления, но для обычных строк они дают одинаковое значение и в CPython обычно один и тот же объект. Полный срез строки не гарантирует создания независимой копии.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

#### Решение

В данном задании необходимо создать 2600 переменных, имена которых состоят из латинской буквы и числа от 0 до 99.

Всего используется 26 латинских букв:

```text
abcdefghijklmnopqrstuvwxyz
```

Для каждой буквы требуется создать 100 переменных.

Следовательно:

```text
26 * 100 = 2600
```

Каждой переменной необходимо присвоить уникальное целочисленное значение от 1 до 2600.

Для решения используем вложенные циклы `for` и функцию `globals()`.

#### 1. Текст программы

```python
letters = 'abcdefghijklmnopqrstuvwxyz'

for i in range(26):
    for j in range(100):
        name = letters[i] + str(j)
        value = i * 100 + j + 1
        globals()[name] = value

print(a0)
print(a99)
print(b0)
print(b99)
print(z0)
print(z99)
```

#### 2. Результат выполнения программы

```text

100
101
200
2501
2600
```

Программа создаёт все 2600 переменных, а затем выводит значения шести из них для проверки.

#### 3. Подробное объяснение работы программы

**Шаг 1. Создание строки с буквами**

```python
letters = 'abcdefghijklmnopqrstuvwxyz'
```

Создаётся строка, содержащая все 26 строчных латинских букв.

Каждый символ строки можно получить по его индексу.

Например:

```python
letters[0]  # 'a'
letters[1]  # 'b'
letters[2]  # 'c'
letters[25] # 'z'
```

Индексация в Python начинается с нуля.

Поэтому первая буква имеет индекс `0`, а последняя — `25`.

**Шаг 2. Внешний цикл**

```python
for i in range(26):
```

Функция `range(26)` формирует последовательность целых чисел от `0` до `25`.

На каждой итерации переменная `i` получает очередное значение.

Это значение используется для выбора буквы из строки `letters`.

Например:

```text
i = 0  → letters[i] = 'a'
i = 1  → letters[i] = 'b'
i = 2  → letters[i] = 'c'
...
i = 25 → letters[i] = 'z'
```

Таким образом, внешний цикл отвечает за выбор буквы в имени создаваемой переменной.

**Шаг 3. Внутренний цикл**

```python
for j in range(100):
```

Функция `range(100)` формирует числа от `0` до `99`.

Внутренний цикл выполняется 100 раз для каждой буквы.

Переменная `j` используется для создания числовой части имени.

Например, если `i = 0`, то выбрана буква `'a'`.

Внутренний цикл последовательно получает значения:

```text
j = 0
j = 1
j = 2
...
j = 99
```

В результате должны появиться имена:

```text
a0
a1
a2
...
a99
```

Когда внешний цикл перейдёт к `i = 1`, будет выбрана буква `'b'`.

Тогда создаются:

```text
b0
b1
b2
...
b99
```

Процесс продолжается до буквы `'z'`.

**Шаг 4. Формирование имени переменной**

```python
name = letters[i] + str(j)
```

Эта строка объединяет букву и число в одно имя.

Разберём её части.

Выражение:

```python
letters[i]
```

получает букву по индексу `i`.

Выражение:

```python
str(j)
```

преобразует целое число `j` в строку.

Это необходимо, поскольку соединять строку и число оператором `+` непосредственно нельзя.

Например, если:

```text
i = 0
j = 15
```

то:

```python
letters[i]
```

возвращает:

```text
'a'
```

А:

```python
str(j)
```

возвращает:

```text
'15'
```

В результате:

```python
name = 'a' + '15'
```

Получаем:

```text
name = 'a15'
```

Важно: на этом этапе `name` — обычная строковая переменная, содержащая текст имени будущей переменной.

Сама переменная `a15` создаётся следующей операцией.

**Шаг 5. Вычисление значения**

```python
value = i * 100 + j + 1
```

Эта формула позволяет присвоить каждой переменной уникальное число.

Разберём её.

`i * 100` определяет начало диапазона значений для выбранной буквы.

`j` определяет положение переменной внутри группы из 100 имён.

`+ 1` необходимо, чтобы значения начинались с `1`, а не с `0`.

Например, для первой буквы `'a'`:

```text
i = 0
```

Формула принимает вид:

```text
value = 0 * 100 + j + 1
value = j + 1
```
Следовательно:

```text
a0  = 1
a1  = 2
a2  = 3
...
a99 = 100
```

Для второй буквы `'b'`:

```text
i = 1
```

Формула:

```text
value = 1 * 100 + j + 1
value = 101 + j
```

Получаем:

```text
b0  = 101
b1  = 102
b2  = 103
...
b99 = 200
```

Для последней буквы `'z'`:

```text
i = 25
```

Формула:

```text

value = 2501 + j
```

Получаем:

```text

z1  = 2502
z2  = 2503
...
z99 = 2600
```

Таким образом, формула обеспечивает последовательное присваивание всех значений от 1 до 2600 без повторений.

**Шаг 6. Создание переменной с помощью globals()**

```python
globals()[name] = value
```

Это главная строка программы.

В лекции 6 рассматривается представление переменных Python как записей в словаре имён.

Функция `globals()` возвращает словарь глобального пространства имён текущего модуля.

В этом словаре ключами являются имена, а значениями — связанные с ними объекты.

Рассмотрим пример:

```python
name = 'a15'
value = 16

globals()[name] = value
```

Здесь:

```python
globals()[name]
```

означает:

```python
globals()['a15']
```

В глобальное пространство имён добавляется запись с именем `'a15'` и значением `16`.

После этого можно обращаться к созданной переменной непосредственно:

```python
print(a15)
```

Результат:

```text
16
```

То есть команда:

```python
globals()['a15'] = 16
```

в данном случае создаёт глобальное имя, к которому можно обратиться как к обычной переменной:

```python
a15
```

Таким образом, `globals()` позволяет формировать имена переменных программно, а не записывать вручную 2600 отдельных присваиваний.

#### 7. Почему нельзя просто использовать обычное присваивание?

```python
a2 = 3
```

Можно использовать цикл, но запись:


сама по себе не создаёт переменную `a0`.

Она только присваивает переменной `name` строковое значение `'a0'`.

Чтобы использовать содержимое строки как имя глобальной переменной, применяется:

```python

```

Именно поэтому в данной задаче использование словаря глобальных имён позволяет решить её компактно.

В обычных программах для хранения большого количества однотипных значений чаще используют списки и словари. Однако здесь по условию требуется создать именно переменные с заданными именами, поэтому использование `globals()` подходит для выполнения задания.
